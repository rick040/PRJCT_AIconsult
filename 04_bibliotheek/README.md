# Bibliotheek

Herbruikbaar materiaal dat af is en bij meerdere klanten inzetbaar. Alles hier is ontdaan van klantdata.

| Map | Inhoud |
|---|---|
| `skills/` | generieke skills per domein, plus het skill-sjabloon |
| `mcp/` | koppelingspatronen per systeem |
| `n8n/` | workflowpatronen |
| `fundament-sjablonen/` | domeinindelingen en mappenstructuren per branche |

## Regel
Iets komt pas in de bibliotheek als het bij minimaal één klant heeft gewerkt én alle klantspecifieke gegevens eruit zijn. Een idee hoort hier niet, een werkend patroon wel.
