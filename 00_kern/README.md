# Kern

Bron van waarheid. Elke agent leest hieruit voordat hij iets maakt. Wijzigen alleen met akkoord van Rick.

| Bestand | Waarvoor | Wie leest het |
|---|---|---|
| `positionering.md` | wie we zijn, wat we wel en niet doen | iedereen |
| `lagenmodel.md` | de inhoudelijke kern van de aanpak | iedereen |
| `prijskaart.md` | elke prijsuitspraak | sales, scan, offerte |
| `personas.md` | Bas, Marloes, Joris | sales, content, offerte, training |
| `usps.md` | onderscheid, op volgorde | sales, content, offerte |
| `bezwaren-en-antwoorden.md` | twaalf bezwaren met vaste antwoorden | sales, offerte, content |
| `tone-of-voice.md` | hoe we schrijven | iedereen die tekst maakt |
| `doelgroep.md` | wie we bedienen en wie niet | sales, scan |
| `klantdossier-template.md` | dossier per klant | iedereen |
| `toolkit-standaard.md` | hoe elke klanttoolkit eruitziet | toolkit-builder, integratie |

## Regel

Staat een prijs, belofte of positioneringszin hier niet in? Dan verzin je hem niet. Melden, of `[TE BEPALEN: ...]` in de output zetten.
