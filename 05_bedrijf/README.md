# Bedrijf

De bedrijfsvoering van PRJCT AI zelf. Geen klantmateriaal.

| Map | Inhoud |
|---|---|
| `framework/` | het basisframework en de open beslissingen |
| `roadmap/` | de routekaart van idee naar draaiende praktijk, in zes blokken |
| `kpi/` | maandelijkse KPI-overzichten |
| `casussen/` | uitgewerkte klantcasussen, alleen met schriftelijke toestemming |

## Waar begin je

`roadmap/routekaart.md`. Dat is het werkdocument: zes blokken, in volgorde, met per blok wat er af moet en waar het landt. Het basisframework is de onderbouwing eronder, geen stappenplan.
